# Типові звернення щодо трекерів

Проаналізовано файл `2022-2025.html`: 722 записи з датою звернення, з них 719 мають опис проблеми.

| Група згадок в описі | Кількість |
| --- | ---: |
| GPRS / GSM | 223 |
| GPS | 128 |
| Не працює | 99 |
| Встановлення на нове авто | 74 |
| Перенесення / заміна | 47 |
| Зависання | 41 |
| Живлення / запобіжник | 20 |
| SIM-картка | 12 |

Це групування за ключовими словами, а не встановлені причини несправностей. Один опис може належати до кількох груп. У формі GPS розділено на «Немає GPS» та «Пропадає GPS» для точнішого вибору. Варіанти швидкого вибору доповнюють опис; його можна редагувати вручну.

Повторити аналіз: `node scripts/analyze-repairs.cjs "шлях/2022-2025.html"`.

Вихідна історія ремонтів не копіюється до публічного коду; збережено лише зведені підрахунки.
