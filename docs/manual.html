🛠️ Журнал ремонту та сервісу трекерів

Центральний реєстр діагностики, монтажів, технічного обслуговування та списання GPS-обладнання.

📝 Як додати новий ремонт
1
Натисніть зелену кнопку «+ Додати ремонт» у верхній панелі.
2
Оберіть дату або натисніть «Сьогодні» у календарику.
3
Вкажіть номер авто / борт, перевізника (зі списку з автодоповненням) та серійний номер трекера.
4
Заповніть несправність, виконані роботи, статус і натисніть «Зберегти».
📦 Пакетна реєстрація («Масове додавання»)
Використовується при отриманні нових партій обладнання (як у реєстрі «НОВІ ТРЕКЕРИ»).
1
Натисніть кнопку «⚡ Масово додати».
2
Вкажіть загальний статус (напр. Встановлено або Офіс).
3
Введіть список серійних номерів (через кому, пробіл або з нового рядка) або діапазон (напр. 023020..023029).
4
Система створить записи для кожного трекера за 1 клік!

🔍 Фільтрація, швидкий пошук та навігація

Пошуковий рядок миттєво знаходить записи за: серійним номером, номером авто, перевізником або текстом виконаних робіт.

Модуль 2 • Складський облік, База AT-команд та Експорт

📦 Склад комплектуючих та База знань

Облік матеріальних залишків для швидкого відновлення трекерів та довідник команд для прошивки.

🧰 Склад деталей та матеріалів
Вкладка «📦 Склад» веде облік витратних матеріалів:
  • SIM-картки (Київстар, Vodafone, Lifecell).
  • Блокувальні реле (12V / 24V), запобіжники.
  • Зовнішні антени GPS/GLONASS та GSM.
  • Роз'єми живлення, корпуси, тримачі SIM.
Керування: Кнопки + та - прямо в картці змінюють кількість без відкриття форми. При досягненні нуля з'являється попередження про необхідність замовлення.
📟 Шпаргалка AT-команд
Вкладка «📟 AT-команди» містить готові команди конфігурації через SMS або термінал (Teltonika, Ruptela, BCE):
  • Налаштування APN мобільних операторів.
  • Встановлення IP та порту сервера моніторингу.
  • Команди перезавантаження (cpureset).
  • Запит поточного статусу та супутників (getinfo).
Копіювання: Кнопка «📋 Копіювати» копіює синтаксис команди в буфер обміну за 1 секунду.

💾 Експорт, Резервні копії та Безпека даних

Для формування звітності для керівництва або перенесення бази використовуйте панель дій:

📥 Експорт в Excel / CSV
Завантажує всю таблицю ремонтів у сумісному форматі для аналізу в Excel або Google Таблицях.
🛡️ Повний JSON-бекап
Створює повний архів бази даних (ремонти, склад, команди) для збереження на локальний диск чи флешку.
🔄 Хмарний резерв
Усі записи автоматично реплікуються в хмарну базу даних Firebase Firestore кожні 350 мс.
ℹ️
Автономність: Якщо на базі зникне інтернет, Tracker Hub автоматично переходить у локальний режим. Ви можете продовжувати додавати та редагувати ремонти — при відновленні мережі всі дані синхронізуються автоматично.

⏱️ SZVK WORK HOURS
Модуль 3 • Графік чергувань, щоденні справи та фокус місяця

📅 Календар чергувань системних адміністраторів

Організація 7-денної сітки чергувань, облік завдань та координація змін Артема та Олександра.

⇄ Чергування та швидкі підміни
Календар побудований зручною сіткою по 7 днів (Пн–Нд):
  • Артем: фіолетовий колір комірки.
  • Олександр: смарагдово-зелений колір комірки.
  • Сьогоднішній день: виділений помітною бурштиновою рамкою зі свіченням.
  • Підміна в 1 клік: у модальному вікні дня кнопка «Змінити чергового» міняє працівника та ставить бейдж ⇄.
📝 Центрований каунтер справ дня
У кожній комірці прямо по центру розміщено інформативний бейдж завдань:
  • Активні справи: яскравий блакитний бейдж із підсвічуванням 📝 2 справи (на мобільному: 📝 2 або 📝 1/3).
  • Виконані справи: зелений бейдж ✓ 3 справи (всі задачі закриті).
  • Клік по дню відкриває модальне вікно для додавання пунктів із галочками.

🎯 Фокус місяця та Таскбари («Загальні нотатки»)

Довгострокові стратегічні завдання, які не прив'язані до конкретного дня, а стосуються всього місяця:

1
Встановлення фокусу: Натисніть на банер із мішенню 🎯 у верхній частині календаря або кнопку «✏️ Змінити» у вкладці «Загальні нотатки».
2
Збереження: Введіть пріоритет (напр. «Масовий монтаж трекерів на ТЕТ та ревізія складу») та натисніть Ctrl + Enter або «Зберегти».
3
Місячні таскбари: У вкладці «Загальні нотатки» додавайте системні справи, відзначайте галочками статус вирішення та видаляйте закриті.

🛡️ Журнал аудиту та захист від випадкових помилок

Обидва сервіси підключені до Єдиного журналу історії дій. Будь-яку операцію можна перевірити, відредагувати або скасувати в 1 клік.

↩️ Як скасувати помилкову дію (Кнопка «Повернути»)
Якщо ви випадково видалили ремонт, змінили статус або скинули чергового:
  1. Відкрийте вкладку «📜 Історія» (у Tracker Hub або Work Hours).
  2. Знайдіть запис операції (за часом, автором чи описом).
  3. Натисніть помаранчеву кнопку «↩️ Повернути» поруч із записом.
  4. Система миттєво відновить видалений або змінений об'єкт до початкового стану!

🔒 Безпека акаунтів та захист доступу

🔑 Хешування паролів (SHA-256)
Паролі не зберігаються у відкритому вигляді в коді. При зміні пароля адміністратора чи користувача в хмарі генерується криптографічний хеш, а старий пароль анулюється безповоротно.
👥 Адмін-панель керування
Адміністратор може додавати нових користувачів, скидати паролі та проводити безпечне скидання періодів чергувань.
